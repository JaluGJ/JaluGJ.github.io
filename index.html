01 / CLOUD PLATFORM

Serverless Business Platform

Independent AWS services and asynchronous analysis workflows to address timeout-related gaps in results.

My contribution: Architecture design, Lambda development and CI/CD.

  • AWS Lambda
  • API Gateway
  • Step Functions
  • CI/CD
Technical details — Serverless Business Platform
Context
The platform needed independent services so a failure in one would not take down the whole system.
Challenge
Metrics and AI analysis ran longer than API Gateway's response window. Timeouts left gaps in the returned information.
Architecture
Separate AWS Lambda services, with Step Functions orchestrating analysis workflows. Polling retrieved AI results when they were ready.
Decisions
I used Step Functions for metrics and AI analysis to decouple processing from the short API response window. Polling avoided keeping the request open while AI processing completed; Lambda execution limits still applied.
My implementation
I proposed the architecture, created Lambda functions and worked on CI/CD.
Outcome
After the change, the system returned analysis without the information gaps previously caused by timeouts. This is a qualitative observation, not a measured availability guarantee.
