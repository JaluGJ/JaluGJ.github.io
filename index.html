Selected work

Systems I've worked on

Representative case studies from my experience. Client names and sensitive details are intentionally omitted.

01 / CLOUD PLATFORM

Serverless Business Platform

Problem
A business product needed a backend that several services could evolve and ship independently across environments.
Solution
A multi-service backend on AWS Lambda and API Gateway, with Cognito-based identity and PostgreSQL persistence.
Architecture decisions
Clear service boundaries and deployment workflows that support independent delivery per environment.
  • AWS
  • Python
  • PostgreSQL
  • Cognito
  • CI/CD
02 / APPLIED AI

AI-enabled Knowledge Workflows

Problem
AI-powered features needed dependable backend support for documents and transcripts, and had to cope with request time limits.
Solution
Backend patterns combining application APIs, document and transcript storage, metadata, embeddings and vector retrieval.
Architecture decisions
Traceable data flows, and asynchronous processing where request time limits apply.
  • Python
  • Amazon Bedrock
  • MongoDB Atlas
  • S3
  • Step Functions
03 / MESSAGING

WhatsApp AI Assistant Integration

Problem
Receive customer messages from WhatsApp and answer them conversationally with an AI assistant.
Solution
Architecture for inbound messages through webhooks, serverless processing and the WhatsApp Cloud API.
Architecture decisions
A flow that supports conversational responses and leaves a path to route messages for multiple businesses.
  • WhatsApp Cloud API
  • Webhooks
  • AWS Lambda
  • API Gateway
04 / PRODUCT ANALYTICS

Operational Metrics Service

Problem
Track daily product metrics and operational failures in a way that can be queried over time.
Solution
Data models and API workflows for daily metrics, upserts, time-window queries and failure tracking.
Architecture decisions
Clear relationships between users, products and metric snapshots.
  • MongoDB
  • Python
  • Data modeling
  • REST APIs
